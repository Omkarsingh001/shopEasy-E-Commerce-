# 🛍️ ShopEase – Modern E-Commerce Website

## 📌 Project Overview

**ShopEase** is a responsive frontend e-commerce website developed as a college project using **HTML, CSS, and JavaScript**. The project simulates a real online shopping platform where users can browse products, search items, manage a shopping cart and wishlist, complete a checkout process, and interact with a modern user interface.

The project demonstrates the practical implementation of frontend web development concepts, including responsive design, DOM manipulation, Local Storage, and dynamic user interactions.

---

## 🎯 Project Objectives

* Develop a responsive e-commerce website using frontend technologies.
* Create an attractive and user-friendly shopping interface.
* Implement dynamic product searching and filtering.
* Manage shopping cart and wishlist using Local Storage.
* Build reusable and maintainable frontend components.
* Provide a realistic online shopping experience without using a backend.

## ▶️ How to Run the Project

1. Download or clone the project.
2. Open the project folder in **Visual Studio Code**.
3. Install the **Live Server** extension (if not already installed).
4. Right-click **index.html** and select **Open with Live Server**.
5. Explore all pages and features using the navigation menu.

---

## 🚀 Deploy to Vercel

This is a static HTML, CSS, and JavaScript project, so it does not need a build command or backend to deploy.

1. Push the project to a GitHub repository.
2. Sign in to [Vercel](https://vercel.com/) and choose **Add New → Project**.
3. Import the `shopEasy-E-Commerce-` GitHub repository and authorize Vercel if prompted.
4. Keep the framework preset as **Other**. Leave the root directory as `./` and leave the build command and output directory blank.
5. Select **Deploy**. Vercel will serve `index.html` and the other project files.

After deployment, each push to the connected GitHub branch will trigger a new deployment. Shopping cart, wishlist, and account data are stored in the visitor's browser using Local Storage; this project does not include a backend.
